========================================
I2C — STUDY NOTES (DS3231 ALARM CLOCK)
========================================


1. THE ONE-SENTENCE IDEA
------------------------
I2C lets one master (STM32) talk to many slaves (DS3231, etc.)
over just two shared wires.

   SCL = the clock (master's heartbeat)
   SDA = the data


2. HOW A BIT ACTUALLY MOVES
---------------------------
   - SDA only CHANGES while SCL is LOW  (LOW = safe zone to set up the next bit)
   - SDA is READ while SCL is HIGH      (HIGH = the moment the bit is captured)

Special signals break the "SDA changes on LOW" rule on purpose,
so they stand out:

   START = SDA drops HIGH->LOW while SCL is HIGH   ->  "everyone listen up"
   STOP  = SDA rises LOW->HIGH while SCL is HIGH   ->  "I'm done"
   ACK   = after each byte, receiver pulls SDA LOW one extra pulse -> "got it"


3. ADDRESSING — CALLING A DEVICE BY NAME
----------------------------------------
Many devices share the wires, so each has a fixed 7-bit address
(DS3231 = 0x68, from its datasheet).

Sent as one byte: 7 address bits + 1 R/W bit.

   byte = (address << 1) | R/W        R/W: 0 = write, 1 = read

The << 1 shifts the 7-bit address up to make room for the R/W bit
at the bottom.


4. BCD — HOW DS3231 STORES TIME
-------------------------------
Each digit is stored separately, so 45 seconds = 0x45 (NOT decimal 69).
Reading it back needs no math — the hex digits ARE the decimal digits.


5. WHO DOES WHAT
----------------
Hardware does:  wiggles the wires, shifts bytes bit-by-bit, sends/receives ACK.
You do:         decide WHEN to START, WHAT byte to drop in DR, and WAIT for the
                right flag before each next step (SB -> ADDR -> TXE/RXNE).


6. SETUP ORDER (memorize this shape — every peripheral follows it)
------------------------------------------------------------------
   1) Clocks on         (GPIO + I2C1)
   2) SWRST             (reset I2C to a clean state)
   3) GPIO pins         (AF mode, open-drain, pull-up, high speed)
   4) I2C timing        (CR2, CCR, TRISE) — peripheral must be OFF
   5) PE                (enable the peripheral — always LAST)


7. OPEN-DRAIN + PULL-UP (the pairing that caused hours of bugs)
---------------------------------------------------------------
   Open-drain     = a pin can ONLY pull LOW, never drive HIGH.
                    -> Makes it SAFE to share a wire: two devices can never
                       fight (no 3.3V-meets-GND short).

   Pull-up resistor = weakly ties the line to 3.3V.
                    -> Makes the wire USABLE: when nobody pulls LOW, the line
                       floats up to a clean HIGH.

   One without the other fails:
      open-drain alone  = floating garbage
      push-pull alone   = short-circuit risk


8. THE TIMING NUMBERS (rebuild them, don't memorize)
----------------------------------------------------
   CR2 (FREQ) = 16
      Input clock in MHz. The field is only 6 bits (max 63),
      which is exactly why it wants MHz, not Hz.

   CCR = 80
      Formula:  clock / (2 x speed) = 16,000,000 / (2 x 100,000) = 80
      The x2 is because one SCL cycle has a HIGH half + a LOW half,
      and CCR counts just one half.

   TRISE = 17
      Formula:  (rise_time x clock) + 1 = (1us x 16MHz) + 1 = 16 + 1
      The +1 rounds up for a safety margin.


9. WRITE SEQUENCE
-----------------
   START
   -> address + write -> wait ADDR -> clear ADDR
   -> register byte   -> wait TXE
   -> data byte       -> wait TXE
   -> STOP


10. READ SEQUENCE (always TWO phases)
-------------------------------------
   Phase 1 (point):
      START -> address + write -> wait ADDR -> clear ADDR
            -> register byte -> wait TXE

   Phase 2 (read):
      repeated START -> address + read -> wait ADDR
      -> disable ACK (BEFORE clearing ADDR, since only 1 byte) -> clear ADDR
      -> STOP -> wait RXNE -> read DR

--- REGISTER DEFINES ---

#include <stdio.h>
#include <stdint.h>

// RCC — turns peripheral clocks on
#define RCC_AHB1      (*(volatile uint32_t*)0x40023830)  // clock enable for GPIO ports
#define RCC_APB1      (*(volatile uint32_t*)0x40023840)  // clock enable for I2C/UART/TIM

// GPIOB — the pin control registers
#define GPIOB_MODER   (*(volatile uint32_t*)0x40020400)  // pin mode: in / out / AF / analog
#define GPIOB_OTYPER  (*(volatile uint32_t*)0x40020404)  // output type: push-pull vs open-drain
#define GPIOB_OSPEEDR (*(volatile uint32_t*)0x40020408)  // how fast a pin can flip HIGH/LOW
#define GPIOB_PUPDR   (*(volatile uint32_t*)0x4002040C)  // internal pull-up / pull-down
#define GPIOB_AFRH    (*(volatile uint32_t*)0x40020424)  // which AF for pins 8-15

// I2C1 — the peripheral itself
#define I2C1_CR1      (*(volatile uint32_t*)0x40005400)  // control: PE, START, STOP, ACK, SWRST
#define I2C1_CR2      (*(volatile uint32_t*)0x40005404)  // input clock frequency (MHz)
#define I2C_DR        (*(volatile uint32_t*)0x40005410)  // data in/out
#define I2S1          (*(volatile uint32_t*)0x40005414)  // status 1: SB, ADDR, TXE, RXNE
#define I2S2          (*(volatile uint32_t*)0x40005418)  // status 2: reading it helps clear ADDR
#define I2C1_CCR      (*(volatile uint32_t*)0x4000541C)  // SCL speed divider
#define I2C_TRISE     (*(volatile uint32_t*)0x40005420)  // rise-time compensation


--- INIT ---

void rtcInit(){
    // 1. Clocks first — nothing responds until powered
    RCC_AHB1 |= (1 << 1);    // GPIOB clock (bit 1)
    RCC_APB1 |= (1 << 21);   // I2C1 clock  (bit 21)

    // 2. Reset I2C to a clean slate
    I2C1_CR1 |= (1 << 15);   // set SWRST — hold in reset
    I2C1_CR1 &= ~(1 << 15);  // clear SWRST — release, now fresh

    // 3. Configure PB8 (SCL) and PB9 (SDA)
    GPIOB_MODER &= ~(0xF << 16); // clear mode bits for pins 8 & 9
    GPIOB_MODER |= (2 << 16);    // PB8 = AF mode (binary 10)
    GPIOB_MODER |= (2 << 18);    // PB9 = AF mode

    GPIOB_OSPEEDR |= (3 << 16) | (3 << 18); // PB8 & PB9 = highest speed
    GPIOB_OTYPER  |= (3 << 8);              // PB8 & PB9 = open-drain (mandatory)
    GPIOB_PUPDR   |= (1 << 16) | (1 << 18); // PB8 & PB9 = pull-up

    GPIOB_AFRH &= ~(0xFF << 0);  // clear AF bits for pins 8 & 9
    GPIOB_AFRH |= (4 << 0);      // PB8 = AF4 -> I2C1_SCL
    GPIOB_AFRH |= (4 << 4);      // PB9 = AF4 -> I2C1_SDA

    // 4. Timing (peripheral still OFF)
    I2C1_CR2  |= 16;   // input clock = 16 MHz
    I2C1_CCR  |= 80;   // 100 kHz: 16M / (2 x 100k)
    I2C_TRISE |= 17;   // (1us x 16MHz) + 1

    // 5. Enable peripheral LAST
    I2C1_CR1 |= (1 << 0);  // PE (bit 0) — I2C is now live
}


--- WRITE ---

void i2cWrite(){
    I2C1_CR1 |= (1 << 8);        // START (bit 8)
    while(!(I2S1 & (1 << 0)));   // wait SB — START confirmed

    I2C_DR = (0x68 << 1) | 0;    // DS3231 address + write bit
    while(!(I2S1 & (1 << 1)));   // wait ADDR — slave ACKed

    volatile uint32_t temp = I2S1; // clear ADDR: read SR1...
    temp = I2S2;                   // ...then SR2

    I2C_DR = 0x00;               // register pointer: seconds (0x00). Plain byte, no shift
    while(!(I2S1 & (1 << 7)));   // wait TXE — DR empty, ready for next

    I2C_DR = 0x02;               // value to store: 2 seconds (BCD)
    while(!(I2S1 & (1 << 7)));   // wait TXE — byte sent

    I2C1_CR1 |= (1 << 9);        // STOP (bit 9) — release bus
}


--- READ ---

int i2cRead(){
    // Phase 1 — point at the seconds register (a write)
    I2C1_CR1 |= (1 << 8);        // START
    while(!(I2S1 & (1 << 0)));   // wait SB

    I2C_DR = (0x68 << 1) | 0;    // address + write
    while(!(I2S1 & (1 << 1)));   // wait ADDR

    volatile uint32_t temp = I2S1; // clear ADDR
    temp = I2S2;

    I2C_DR = 0x00;               // register pointer: seconds
    while(!(I2S1 & (1 << 7)));   // wait TXE

    // Phase 2 — switch to reading
    I2C1_CR1 |= (1 << 8);        // repeated START (change direction)
    while(!(I2S1 & (1 << 0)));   // wait SB

    I2C_DR = (0x68 << 1) | 1;    // same address + read bit
    while(!(I2S1 & (1 << 1)));   // wait ADDR

    I2C1_CR1 &= ~(1 << 10);      // disable ACK (bit 10) BEFORE clearing ADDR — only 1 byte
    temp = I2S1;                 // clear ADDR
    temp = I2S2;

    I2C1_CR1 |= (1 << 9);        // STOP — queued to fire after the byte

    while(!(I2S1 & (1 << 6)));   // wait RXNE — byte has arrived
    uint8_t seconds = I2C_DR;    // read it out

    return seconds;              // hand value back to caller
}

12. BUGS TO WATCH FOR (from real debugging)
========================================
   - Wrong pins — verify against the board schematic (it was PB8/PB9, not PB6/PB7).
   - Missing open-drain        -> stuck at SB / ADDR.
   - Missing OSPEEDR / PUPDR   -> flaky signal.
   - Missing SWRST             -> peripheral won't start cleanly.
   - Wrong bit numbers         -> always check the reference manual, never guess.
   - \n without \r in UART     -> text stair-steps to the right.
